# ครอบครัวสุขภาพ

บันทึกประวัติสุขภาพคนในครอบครัว แอปแบบ **Coupled**: หน้าจอ, ชนิดข้อมูล และที่เก็บข้อมูลอยู่ในโปรเจกต์ Next.js เดียวกัน เรียกผ่าน Server Actions ไม่มีระบบล็อกอิน และไม่มี API แยก

## สแตก

- Next.js (App Router) + TypeScript
- Tailwind CSS และ MUI
- ข้อมูลอยู่ใน `data/store.json` บนเครื่องที่รันแอป

## เริ่มใช้

```bash
npm install
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000) แล้วเพิ่มสมาชิกในบ้าน จากนั้นบันทึกโรค ประวัติแพ้ ยา วัคซีน การพบแพทย์ และสัญญาณชีพ

อย่าเปิดพอร์ตนี้สู่สาธารณะ ไฟล์ข้อมูลมีประวัติสุขภาพและไม่มีระบบตรวจสิทธิ์
